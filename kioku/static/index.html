    Memory grows through habits, not chat alone: a journal every night, a briefing every morning, a weekly review on Sunday, a monthly review on the 1st. Each one reads the level below it and updates the topic notes and the index Kioku reads first.

    1. Every night — daily journal: today's talk and notes → key points, decisions, open questions, topic updates Lightning
    2. Every morning — briefing: what is still open, tasks, and the same day last week / month / year Lightning
    3. Sunday — weekly review: the week's journals → patterns, decisions, what didn't work; topics' current state; lasting facts Super
    4. 1st of the month — monthly review: the month's weeks → numbers, trends, lessons Super

    Tip: talk to Kioku first, then write tonight's journal — your conversation becomes part of the memory.
